# Wiki Mermaid 渲染

在 Confluence Wiki 页面中，把代码块里的 mermaid 源码直接渲染成图形，无需跳转外部工具。

## 功能

- **自动渲染**：扫描页面中的 mermaid 代码块并渲染为图形，保留原代码块，可随时切换「查看源码 / 查看图形」。
- **图形交互**：
  - 默认可框选并复制图中文字。
  - 超宽图首次显示时自动适应内容宽度。
  - 支持放大 / 缩小 / 恢复 100% / 适应宽度。
  - 拖动模式下可用滚轮缩放，并可拖出当前视图 50% 的留白。
  - 支持覆盖当前网页的全屏查看，按 Esc 退出并恢复进入前状态。
  - 一键复制源码。
- **大图折叠**：超过阈值的大图默认折叠，可随时展开/收起；弹窗中支持「全部收缩 / 全部展开」。
- **渲染开关**：弹窗中可即时启用或关闭渲染，对已打开的页面立即生效。
- **自定义站点**：内置支持 `https://*.atlassian.net/wiki/*`，也可粘贴任意 Confluence 站点地址并授权，插件会按站点注册渲染脚本。

## 支持环境

- Atlassian Cloud（`*.atlassian.net`）
- Confluence Server（代码宏）
- Atlassian Design System 代码块、Live Doc（ProseMirror / CodeMirror）及常见 `pre` 代码块
- 通过「自定义 Wiki 站点」扩展的其它站点

## 安装

1. 打开 Chrome 扩展管理页 `chrome://extensions/`。
2. 开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本项目目录。

## 使用

1. 打开包含 mermaid 代码块的 Wiki 页面，代码块会自动渲染为图形。
2. 点击扩展图标，在弹窗中控制渲染开关、大图折叠，以及收缩/展开当前页所有图形。
3. 若站点未被内置支持，在弹窗「自定义 Wiki 站点」中粘贴页面地址，授权后刷新对应页面即可。
